# Surse și verificări pentru 2027

Ultima verificare a paginilor de mai jos: **21 octombrie 2026**.

| Sursă | Ce confirmă și ce nu |
| --- | --- |
| [Consultarea Ministerului din 5 octombrie 2026](https://www.edu.ro/cons_pub_PO_83_84_26_admitere_liceu_27_28) | Existența unor proiecte de metodologie și calendar; nu adoptarea lor |
| [Proiect de metodologie, octombrie](https://edu.ro/sites/default/files/2026-10/PO_AdLic_metodologie_anexa.pdf) | Textul propus; nu este folosit drept regulă finală în acest pachet |
| [Proiect de calendar, octombrie](https://edu.ro/sites/default/files/2026-10/PO_Calendar_AdLic_2027_2028_anexa.pdf) | Calendar propus; nu copia termenele fără ordinul final |
| [Pagina Ministerului despre admitere](https://www.edu.ro/admitere-liceu-si-inv-profesional) | Punct de pornire pentru ordine și anexe; verifică anul fiecărui document |
| [ISMB — Admitere](http://ismb.edu.ro/index.php/admitere) | Broșură, erată și proceduri locale; verifică anul și versiunea |
| [Portalul oficial de admitere](https://admitere.edu.ro/) | Ierarhii și rezultate; verifică anul afișat |

Ediția de față nu certifică un ordin final pentru 2027–2028. Versiunile anterioare
ale ghidurilor se bazau pe propunerea din august; calendarul și ipoteza concursului
pentru 50% din locuri din acea versiune nu sunt reguli curente ale pachetului.

## Lista de verificare înainte de fiecare etapă

- [ ] Anul școlar și ordinul final, cu număr, dată și anexe.
- [ ] Formula mediei și criteriile de departajare.
- [ ] Rutele eligibile, probele și echivalările necesare.
- [ ] Broșura actuală, erata, codurile și locurile pe ruta relevantă.
- [ ] Procedura și termenele CES, dacă este cazul.
- [ ] Data, ora și canalul depunerii fiecărei cereri și a dosarului.
- [ ] Condițiile etapelor ulterioare și efectul asupra locului deja obținut.

Înregistrează URL-ul, documentul, anul, data consultării și stadiul în
[modele/termene.csv](modele/termene.csv). Dacă un document lipsește, marchează-l
„de verificat”; absența dintr-o căutare nu dovedește că nu a fost publicat.
