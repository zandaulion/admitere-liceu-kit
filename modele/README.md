# Șabloane sintetice

Copiază CSV-urile într-un folder privat. În Excel/LibreOffice alege UTF-8 și
separatorul virgulă; păstrează codurile ca text. Rândurile DEMO sunt fictive:
șterge-le și completează numai după verificarea broșurii/eratei anului curent.
Șabloanele nu sunt formulare oficiale și nu se trimit pentru înscriere.

- [optiuni.csv](optiuni.csv): preferință, cod, școală, specializare, rută, locuri,
  prag și anul lui, navetă, sursa și verificarea eligibilității.
- [termene.csv](termene.csv): etapă, termen, sursă, an școlar și stadiu. Termenele
  sunt intenționat goale: completează-le din documentele oficiale actuale.
- [coduri-demo.json](coduri-demo.json) și [fisa-demo.json](fisa-demo.json):
  trei specializări fictive și lista ordonată pentru exemplul din
  [SCRIPTURI.md](../SCRIPTURI.md). Codurile DEMO nu sunt coduri reale de înscriere.

Sortează toate coloanele împreună. Nu adăuga nume de copii, coduri de candidat,
adrese, diagnostice, acte sau copii de certificate în tabele destinate partajării.
